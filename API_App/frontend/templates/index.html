Marine Buoy Weather Forecasting

This application provides weather forecasting and buoy similarity analysis for NOAA buoys in the Gulf of Mexico and Pacific Ocean.

Two meteorological variables are predicted one hour into the future using time-series regression with lag features:

  • WVHT — Significant Wave Height (m)
  • WTMP — Water Temperature (°C)

Models compared: Persistence baseline, Ridge Regression, Random Forest, Gradient Boosting and AutoML (FLAML). The best model is selected on validation RMSE using a chronological 70/15/15 split.

Buoy similarity is analyzed via KMeans clustering on meteorological profiles, with silhouette score for automatic k selection and PCA for 2D visualization.
